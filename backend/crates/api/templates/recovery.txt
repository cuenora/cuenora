Password recovery

Reset your password.

Copy this password recovery token:

{{TOKEN}}

In a terminal, run python3 scripts/recover_password.py and enter this token when prompted. This token expires 30 minutes after it was issued and can be used once.

After you save a new password, you will be signed out on every device. Sign in again with your new password.

If you did not request a password reset, ignore this email. Your password will stay the same. Do not share this token.
